# sapr

Для доступа обращайтесь в [личные сообщения канала](http://t.me/tgcoffeeforcoffer)

Программа предназначена для автоматизации прочностных расчётов плоских стержневых конструкций, работающих на растяжение и сжатие. Она позволяет создавать расчётные схемы из нескольких последовательно соединённых стержней, задавать их геометрические характеристики, свойства материала и внешние нагрузки. На основе введённых данных программа формирует графическое представление конструкции и выполняет необходимые вычисления для определения перемещений, продольных сил и нормальных напряжений.

Работа программы заключается в обработке исходных данных и выполнении расчётов для всей заданной конструкции. Полученные результаты отображаются в виде графиков и эпюр, позволяющих оценить распределение расчётных величин по длине стержней. Также предусмотрена возможность расчёта в отдельной точке или с заданным шагом, при котором значения автоматически заносятся в таблицу. После завершения работы пользователь может сохранить результаты и сформировать отчёт, содержащий исходные данные, расчётную схему, графики и таблицы с полученными значениями.
